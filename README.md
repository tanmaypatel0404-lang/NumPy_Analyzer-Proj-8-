# 🔢 NumPy Analyzer

### A Simple Python Project for Array Operations and Statistical Analysis

NumPy Analyzer is a menu-driven Python application developed using **NumPy and Object-Oriented Programming (OOP)**. It allows users to create and manage NumPy arrays, perform mathematical calculations, combine or split arrays, search and filter values, and calculate important statistical measures.

The project provides a simple console-based interface that makes numerical computations easy to understand and perform. It is designed as a beginner-friendly project to practice Python programming, array manipulation, and statistical analysis.

---

## ✨ Features

### 📊 1. Array Creation and Management
- Create one-dimensional (1D), two-dimensional (2D), and three-dimensional (3D) NumPy arrays.
- Enter array elements directly through user input.
- Display arrays in a readable format.
- Perform indexing and slicing to access selected elements.

### ➕ 2. Mathematical Operations
Perform calculations on two arrays of compatible shapes, including:
- Addition
- Subtraction
- Element-wise multiplication
- Division with zero-division checks
- Dot product for compatible 2D arrays

### 🔗 3. Combine and Split Arrays
- Combine two arrays horizontally or vertically.
- Split an existing array into multiple sections.
- Display the resulting arrays after each operation.

### 🔍 4. Search, Sort, and Filter
- Search for a particular value in an array.
- Sort array elements in ascending order.
- Filter values based on a user-defined condition.

### 📈 5. Statistical Analysis
Calculate useful statistical properties of numerical data, including:

- Sum and mean
- Median
- Standard deviation
- Variance
- Minimum and maximum values
- 25th, 50th, and 75th percentiles
- Correlation coefficient between two arrays

### 🧩 6. Object-Oriented Programming
The project demonstrates important OOP concepts through:
- Classes and objects
- Encapsulation using a private instance attribute
- Instance methods
- Class methods using `@classmethod`
- Static methods using `@staticmethod`

### 🖥️ 7. Menu-Driven Interface
The application provides a numbered menu that allows users to select operations, enter values, view results, and exit the program conveniently.

## ⚙️ Installation and Setup

**Step 1: Install Python**

Download Python from [python.org](https://www.python.org/downloads/) and complete the installation.

**Step 2: Install NumPy**

Open the VS Code terminal and execute:

```bash
python -m pip install numpy
```

**Step 3: Download or clone the project**

If using Git, run:

```bash
git clone YOUR_REPOSITORY_URL
```

Alternatively, download the repository as a ZIP file and extract it.

**Step 4: Run the application**

Open the project folder in VS Code and execute:

```bash
python main.py
```

Follow the on-screen instructions to select an operation and enter the required values.
